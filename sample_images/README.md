# 🦐 Sample Images (`sample_images/`)

โฟลเดอร์สำหรับใส่รูปตัวอย่างกุ้งเพื่อให้ผู้ใช้สามารถคลิกทดสอบบนหน้าเว็บ Streamlit ได้ทันที โดยไม่ต้องอัปโหลดภาพเอง

### โครงสร้างโฟลเดอร์:
- `fresh/` — สำหรับใส่ภาพตัวอย่างกุ้งสด (`.jpg`, `.png`, `.webp`)
- `not_fresh/` — สำหรับใส่ภาพตัวอย่างกุ้งไม่สด (`.jpg`, `.png`, `.webp`)
